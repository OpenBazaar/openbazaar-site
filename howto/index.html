Get the app

Howto · version 0.1.0 alpha 21

Install it, open it, and it runs

One app does everything. Open it and your shop and wallet are running; quit and they stop. There is no account, no server to rent, and nothing else to install.

macOS (Apple silicon and Intel): download the .dmg from the downloads. Since alpha 15 the Mac app is signed and notarized by Apple, so it opens normally. Older builds, before alpha 15, may not open: if the dialog says the app is damaged and offers no way to open it, the app is not damaged. macOS marks a download it cannot verify that way. Open Terminal and run xattr -cr /Applications/OpenBazaar.app, then open the app normally.

When you update on macOS, it asks once more whether OpenBazaar may use the key it keeps in your Keychain. Choose “Always Allow”. Since alpha 10 the app waits for your answer and says it’s waiting, instead of failing to start while the question is open.

Windows: the -setup.exe. When SmartScreen says it protected your PC, choose “More info”, then “Run anyway”.

Linux: the .AppImage (make it executable with chmod +x first), or the .deb for Debian and Ubuntu.

To keep a shop open around the clock, run the home version on a spare always-on computer instead, and manage it from your laptop or Android phone. Each download includes its setup guide, home-node.md.

Test coins only This is an early test version on test networks, where coins are free and worth nothing. Don’t send it real money. Every download and its checksum is on the downloads section of the homepage.

The network

Is it over Tor? Yes, on its own

The app runs its own Tor client (Arti) inside its node. There is nothing to install or configure, and no setting that turns it off.

Browsing shops, chain and price queries, order mail and escrow mail all leave through that Tor client, and your shop’s address is a Tor onion address. A shop on the ordinary web is refused before any connection is made, and there is no fallback that quietly skips Tor.

Versions up to alpha 3 did not bundle Tor: they looked for one already running on the machine at 127.0.0.1:9050, and stayed offline without it rather than touch the clear web. If an old build sits silent, that’s why. Update the app instead of installing Tor.

Coins

Monero is already on

Since alpha 4 there is nothing to set up: the app connects to public Monero daemons through Tor on its own. In these test builds that’s Monero’s stagenet, so the coins are worthless on purpose.

A shop that accepts Monero can be paid as soon as the app runs. It’s direct pay, without escrow, and the first sync can take a while.

To use your own Monero server instead, write its URL on one line in a file named xmr-daemon in the app’s data folder and restart the app. Zcash works the same way: a zec-indexer file overrides the built-in test server.

The app’s data folder is ~/.local/share/app.openbazaar.desktop on Linux, ~/Library/Application Support/app.openbazaar.desktop on macOS, and %APPDATA%\app.openbazaar.desktop on Windows.

Qubes OS and minimal Linux

When there is no keyring

The key that encrypts the app’s data lives in your system’s keyring: the macOS Keychain, the Windows Credential Manager, or on Linux the Secret Service.

A plain Fedora or Debian qube usually runs no Secret Service, and versions up to alpha 4 quit right at startup there, with the reason written only to the node’s log. From alpha 5 the app says what happened and offers to keep the key in a file in its data folder instead, readable only by your user. It remembers the choice, so it asks once.

On an older build, install and start gnome-keyring in the template, or just update: alpha 21 is on the downloads.

When a start fails for any reason, the “why” is the last ob-node: line of testnet4/node.log in the app’s data folder. The log stays on your machine; nothing is reported anywhere, so include that line when you file an issue.
